To accurately model the complex socio-ecological dynamics of municipal waste management, the simulation operates on a highly structured dual timescale and a spatially explicit environment \citep{Brugiere2022}.

\paragraph{Spatially Explicit Grid Architecture}
The physical environment is represented as a $50 \times 50$ \texttt{MultiGrid}. Crucially, the grid is configured as **non-toroidal**, ensuring that agents cannot "wrap around" the edges of the municipality—a constraint that preserves the geographical integrity of the seven distinct barangays. This spatial layer facilitates the explicit movement of \texttt{EnforcementAgent} objects and calculates the local social norm influence based on the density of compliant households within a defined Moore neighborhood \citep{TianReview2024}.

\paragraph{Dual-Clock Temporal Resolution}
The simulation utilizes a dual-timescale architecture to capture the friction between micro-level human behavior and macro-level administrative governance \citep{Akbarpour2021}:
\begin{itemize}
    \item \textbf{Daily Micro-Ticks:} At the micro-level, the environment processes daily iterations (1 tick = 1 day). During each tick, \texttt{HouseholdAgents} execute routine interactions, evaluate behavioral friction via their TPB utility functions, and face the stochastic probability of being caught by patrolling \texttt{EnforcementAgents}.
    \item \textbf{Quarterly Policy Epochs:} The macro-level operates on a 90-day epoch. Every 90 ticks, the simulation execution pauses to allow the \texttt{MayorAgent} to interface with the Deep Reinforcement Learning (DRL) policy.
\end{itemize}
The total simulation horizon is fixed at $T = 1,080$ ticks (50,000 during training), representing the standard three-year political term of Philippine local officials.

\subsection{Polycentric Governance: The Coupled ABM-RL Loop}

The model implements a polycentric governance structure as mandated by R.A. 7160 and R.A. 9003 \citep{RA9003, Ostrom2010}. The interaction between these layers is governed by a closed-loop Markov Decision Process (MDP) where the \texttt{MayorAgent} acts as the policy actuator.

\paragraph{The HuDRL Action Space}
Every 90 days, the Mayor Agent observes a 17-dimensional state vector and outputs a 21-dimensional action vector \(\mathcal{A}\in [-1, 1]^{21}\) \citep{TianReview2024}. In this continuous action space, `-1` denotes the minimum possible normalized budget share (effectively zero allocation after Temperature-Scaled Softmax normalization) and `+1` denotes the maximum possible raw preference weight a dimension can carry before normalization. These raw values are never used directly as monetary allocations; they pass through a Temperature-Scaled Softmax (Equation 3.20) that maps the entire vector to non-negative proportions summing to 1, which are then scaled by the quarterly budget cap.

This vector is partitioned into consecutive triplets for each of the seven barangays, where each triplet \(A_{B_i}\) corresponds to one barangay:
\begin{equation}
    A_{B_i} = \{\text{Enforcement Allocation},\ \text{Incentive Allocation},\ \text{IEC Allocation}\}
\end{equation}

For illustration, suppose the Mayor Agent outputs the raw 21-value vector \([-0.42, 0.87, -0.11, -0.30, 0.65, 0.20, \dots]\). The vector is partitioned into consecutive triplets:
\begin{itemize}
    \item \textbf{Barangay 1 (Poblacion):} indices 0-2 \(\rightarrow (-0.42, 0.87, -0.11) \xrightarrow{\text{Softmax}} (\text{\textpeso}0.12\text{M}, \text{\textpeso}0.68\text{M}, \text{\textpeso}0.20\text{M})\)
    \item \textbf{Barangay 2 (Binuni):} indices 3-5 \(\rightarrow (-0.30, 0.65, 0.20) \xrightarrow{\text{Softmax}} (\text{\textpeso}0.14\text{M}, \text{\textpeso}0.54\text{M}, \text{\textpeso}0.32\text{M})\)
    \item \dots and so on for all 7 barangays.
\end{itemize}
Within each triplet, the first element is mapped to Enforcement Allocation, the second to Incentive Allocation, and the third to IEC Allocation for that barangay. This allows the AI to develop highly localized ``triage'' strategies—for instance, deploying heavy enforcement in low-compliance areas like Poblacion while shifting to education-heavy strategies in high-compliance areas like Binuni.

\paragraph{Reward Shaping and Redemption Reset}
To prevent ``policy inertia,'' the simulation enforces a quarterly \textit{Redemption Status Reset}. Every 90 days, all households' incentive eligibility flags are cleared. Households must re-demonstrate compliance within the new quarter to qualify for municipal rewards. 

Computationally, the HuDRL's performance is evaluated via a complex reward function \(R_{t}\) defined in the \texttt{BacolodGymEnv}. The reward function prioritizes ``Jackpot Rewards'' for compliance gains while penalizing ``Administrative Waste'' (over-funding saturated areas) and ``Political Collapse'' (when approval drops below \(10\%\) ).

\paragraph{Data Representation: Algorithm 1 Input and Output}
The simulation environment is constructed from two primary input data structures that initialize the agent-based model (ABM). First, the \textbf{Spatial Grid} is represented as a \(50 \times 50\) integer array, where each cell \(c_{ij} \in \{0, 1, ..., 7\}\) corresponds to a physical location within the municipality. The value \(0\) denotes empty space, while integers \(1\) through \(7\) identify the barangay occupying that cell. Second, the \textbf{Household Registry} is a Python dictionary that maps specific grid coordinates to attribute objects for each individual household. Each attribute object holds necessary state variables, including a \texttt{barangay\_id}, a categorical \texttt{income\_level}, a \texttt{baseline\_attitude} score, and a boolean \texttt{is\_compliant} flag. During the simulation execution, Algorithm 1 utilizes these data structures to instantiate the agents and populate the environment dynamically. The algorithm's output is a continuous \textbf{Policy Action} vector, \(A_t \in \mathbb{R}^{21}\), which represents a 21-dimensional budget allocation across the 7 barangays and 3 policy levers. As detailed in Section 3.4.2, this raw action vector undergoes a Temperature-Scaled Softmax normalization to ensure all allocations sum precisely to the quarterly budget cap while prioritizing high-confidence investments based on the agent's policy.

\begin{algorithm}[htbp]
\caption{The Coupled ABM-RL Main Simulation Loop (Plain English)}
\label{alg:main_loop_english}
\begin{algorithmic}[1]
\State \textbf{Setup:} Create a 50 by 50 flat map (see Figure \ref{fig:data_rep_alg1} for the grid layout) and set the starting yearly budget to \textpeso 1.5 million.
\State \textbf{Instantiation:} Create 7 Barangay agents and populate the map with household agents using real census numbers.
\For{every single day from Day 1 to Day 1080 (roughly 3 years)}
    \State \textbf{// Phase 1: Quarterly AI Planning}
    \If{it is the end of the quarter (every 90 days)}
        \State Gather the current situation: check people's compliance, attitudes, remaining budget, and the Mayor's political support.
        \State Ask the AI to decide the next best action based on this current situation.
        \State Convert the AI's decision into a new budget plan for the 7 Barangays.
        \State \textbf{Reset:} Clear all household reward trackers to start fresh for the new quarter.
    \EndIf
    \State \textbf{// Phase 2: Daily City Life}
    \For{each Barangay}
        \State Carry out daily tasks like sending out local patrols (Tanods) and making public announcements (Recorida).
    \EndFor
    \For{each Household}
        \State Weigh the decision to segregate trash by comparing community peer pressure against the fear of getting fined.
        \State Decide to either follow the rules (Compliant) or ignore them (Non-compliant).
    \EndFor
    \State \textbf{// Phase 3: Enforcement and Consequences}
    \State Enforcers patrol the map, catch violators, and collect fines (which get added back to the budget).
    \State Update the Mayor's political support (fining people too harshly lowers support).
    \If{the Mayor's political support drops to 10\% or lower}
        \State \textbf{Stop the simulation:} The local government has collapsed due to low public support.
    \EndIf
\EndFor
\end{algorithmic}
\end{algorithm}
